# Снежный браузер

Свой браузер для Windows: страницы показывает движок Microsoft Edge (WebView2, тот же Chromium),
а всё вокруг — вкладки, пространства, стартовая, блокировщик, панель — своё.

Запуск: ярлык **«Снежный браузер»** на рабочем столе и в меню «Пуск».
Программа стоит в `%LOCALAPPDATA%\Programs\SneznyjBrowser` — один файл `SneznyjBrowser.exe` (127 МБ, .NET внутри), исходники — здесь.

## Как поставить другу

Отправить один файл **`SneznyjBrowser-Setup-<версия>.exe`** (≈48 МБ). Свежий всегда лежит в
`OneDrive\Рабочий стол\Claude Проекты\Программы и боты\Снежный браузер`, после выкладки — и на GitHub Releases.

- Ставится только для текущего пользователя: права администратора и .NET не нужны. Нужна Windows 10 или 11
  и движок Microsoft Edge WebView2 (в Windows 11 есть всегда, в Windows 10 почти всегда; если нет — установщик даст ссылку).
- Файл пока не подписан сертификатом, поэтому Windows при первом запуске покажет «Windows защитила ваш компьютер»:
  **Подробнее → Выполнить в любом случае**. Браузер при скачивании может написать «файл редко скачивают» — «Сохранить».
- Установщик кладёт программу в `%LOCALAPPDATA%\Programs\SneznyjBrowser`, ярлыки на рабочий стол (по галочке) и в «Пуск»,
  запись в «Параметры → Приложения» (оттуда же удаление; данные удаляются только по отдельной галочке).
- Без окон: `SneznyjBrowser-Setup-x.y.z.exe --silent [--no-desktop-shortcut] [--launch]`,
  удаление — `Uninstall.exe --uninstall --silent [--remove-data]`.

При первом запуске браузер спрашивает, с чего начать: **«Всё в одном»** (одно пространство с популярными сайтами),
**«Дом, работа, отдых»** (три пространства) или **«С чистого листа»**, и какой поисковик ставить. Личных ссылок
Павла там нет — его набор (Сайты, Аналитика, Игры, Алина, Личное) живёт только в его папке данных.

## Что умеет

Всё устроено как в Яндекс Браузере, только без слежки.

- **Вкладки сверху** (или списком слева — переключается в настройках и в меню «≡» → «Вид»). Вкладки сжимаются, когда их много,
  колесо мыши прокручивает полосу. Перетаскивание мышью, средняя кнопка — закрыть, на пустом месте — новая вкладка.
- **Закреплённые вкладки**: только значок, всегда первые (правый клик по вкладке → «Закрепить»).
- **Группы вкладок** с названием и цветом: правый клик → «Добавить в новую группу». Клик по ярлычку группы сворачивает её
  в один ярлычок, правый клик — переименовать, цвет, закрыть группу, перенести в другое пространство. Ссылки из вкладки группы
  открываются в той же группе.
- **Левая панель**: поиск (`Ctrl+K`), сайты боковой панели, закладки, история, загрузки и настройки. Когда вкладки сверху,
  она узкая (132 точки) и выезжает быстро; когда вкладки слева — широкая, со списком вкладок и пространствами. Три режима:
  **закреплена**, **узкая и раскрывается при наведении** (по умолчанию) и **выезжает от левого края**. Булавка в панели
  закрепляет/открепляет, анимацию можно выключить.
- **Темы**: «Как в Windows», 5 тёмных (Снежная ночь, Графит, Полночь, Лес, Камин) и 4 светлых (Светлая, Песок, Мята, Лаванда)
  плюс свой цвет акцента. Меняются сразу, без перезапуска. Сайты, которые умеют, подстраиваются под тёмную или светлую тему.
- **Стартовая (Табло, как в Яндексе)**: часы, поиск и плитки сайтов — у каждого пространства свои. Плитка «Добавить»
  открывает окно с адресом и названием и подсказками: «Вы часто открываете» (из истории) и «Популярные сайты» — клик сразу
  добавляет плитку. Плитки перетаскиваются; на плитке ✎ и × (убрать, с кнопкой «Вернуть»), правый клик — открыть в новой
  или фоновой вкладке, изменить, убрать. Крупные логотипы браузер берёт с самих сайтов (apple-touch-icon и значки с главной,
  без сторонних сервисов) и слегка окрашивает плитку в цвет сайта. Фоны — северное сияние, закат, океан, горы, космос,
  однотонный или своя картинка, снег. Кнопка «Фон» внизу справа.
- **Закладки**: звёздочка в адресной строке (`Ctrl+D`) — закладка сразу добавлена, в окошке можно поменять название, папку
  и вынести на стартовую. Панель закладок с папками, «Другие закладки», менеджер `Ctrl+Shift+O` (папки, перетаскивание, поиск).
  **Перенос из Яндекс Браузера, Chrome и Edge** — одной кнопкой, файл закладок читается прямо с этого компьютера.
- **Умная адресная строка**: подсказки из открытых вкладок, закладок и истории, дописывание адреса (`you` → `youtube.com`),
  `Ctrl+Enter` — `www.….com`. Подсказки поисковика — только если включить (тогда набираемый текст уходит поисковику).
- **Загрузки**: кнопка с кольцом прогресса, окошко последних файлов, страница `Ctrl+J` (открыть, показать в папке, пауза,
  отмена, скачать снова). Папку и «спрашивать каждый раз» можно выбрать в настройках.
- **История** `Ctrl+H` с поиском по дням, удаление отдельных страниц.
- **Жесты мыши** (зажать правую кнопку и провести): ← назад, → вперёд, ↑↓ обновить, ↓→ закрыть вкладку, ↑ новая вкладка,
  ↓↑ вернуть закрытую, ↑← / ↑→ соседняя вкладка, ↓ в самый низ, →← в самый верх. Со следом и подсказкой; выключаются в настройках.
- **Режим чтения** (значок книги в адресной строке на страницах со статьёй): только текст и картинки, размер и шрифт, сепия/ночь.
- **Поиск на странице** `Ctrl+F` со счётчиком «3 из 12», **масштаб** запоминается для каждого сайта (значок «110%» в адресной
  строке — вернуть 100%), **скриншот** видимой части или всей страницы (`Ctrl+Shift+S`, файл в «Изображения\Снежный браузер»
  и в буфер обмена), **перевод страницы** (через переводчик Google или Яндекса — адрес уходит переводчику только по этой команде),
  печать и сохранение страницы.
- **Меню «≡»** со всем этим и **настройки** `sneznyj://settings` (`Ctrl+,`): внешний вид, вкладки и панель, стартовая, поиск,
  жесты, защита, загрузки, боковая панель, о браузере и горячие клавиши. Поиск по настройкам.
- **Пространства** — прямо слева от вкладок: текущее с названием, остальные значками. У каждого свои вкладки, группы
  и стартовая. Клик по текущему — список пространств и «Новое пространство», правый клик — переименовать, сменить цвет,
  удалить. Вкладку можно перетащить на значок другого пространства. `Alt+1…9` — переключать.
- **Ctrl+K** — одно окно для всего: вкладки, закладки, история, плитки, команды и поиск. Понимает неправильную раскладку (`vtnhbrf` → «метрика»).
- **Блокировщик рекламы и трекеров** (щит, рядом счётчик). Клик по щиту — отключить на этом сайте. **Сначала HTTPS**:
  ссылки `http://` открываются защищённо, если сайт умеет.
- **Боковая панель** (`Ctrl+Shift+B`): Telegram, WhatsApp, ВКонтакте, почта — рядом с сайтом; свои сайты добавляются в настройках.
  **«Любой сайт»** (значок глобуса): в строке адреса панели набираете любой адрес или запрос — он открывается справа, основная
  страница остаётся слева. Кнопка «Поровну» делит окно пополам, «+» оставляет сайт в панели отдельным значком.
  Ещё: правый клик по вкладке → «Открыть рядом», по ссылке → «Открыть ссылку рядом», меню «≡» → «Открыть сайт рядом».
- **Вход через Google, ВК, Яндекс** во всплывающем окне: окно входа открывается вкладкой, а когда закрывается само,
  браузер возвращает на сайт, где нажимали «Войти». (До 0.3.1 обёртка движка на `window.close()` закрывала весь браузер.)
  Ошибки, если что-то пойдёт не так, пишутся в `crash.log` в папке данных — браузер при этом не закрывается.
- **Приватные вкладки** (`Ctrl+Shift+N`), **спящие вкладки**, восстановление вкладок (или «начинать со стартовой»),
  звук во вкладке, полный экран (`F11`).
- **Обновляется сам**: раз в сутки проверяет новую версию и показывает слева внизу «Новая версия … — Обновить / Позже».
  Вручную: меню «≡» → «О браузере и обновления».

## Безопасность и где лежат данные

- Всё хранится только на этом компьютере: `%LOCALAPPDATA%\SneznyjBrowser` (профиль, сессия, история, настройки). Никакой своей «облачной» части и сбора статистики у браузера нет.
- Движок Edge **обновляется сам** вместе с Windows: дыры в движке закрывает Microsoft, как у Edge и Chrome.
- SmartScreen включён: проверяет сайты и загрузки на фишинг и вирусы (для этого адреса проверяются у Microsoft).
- Страницы не имеют доступа к программе: мост «страница → программа» выключен, команды принимаются только от своих страниц
  (`https://start.sneznyj/…` — стартовая, настройки, история, загрузки, закладки, режим чтения). Свои страницы не открываются
  во фреймах чужих сайтов, текст с сайтов вставляется только как текст.
- Жесты мыши только наблюдают за правой кнопкой над страницей активного окна браузера: события мыши не перехватываются.
- Пароли браузер может запоминать — они шифруются средствами Windows, как в Chrome и Яндексе. Карты и адреса автозаполнением **не** сохраняются (выключено). Для важного лучше менеджер паролей (Bitwarden, KeePassXC).
- На сайтах без HTTPS в адресной строке жёлтый значок: там не вводить пароли и карты.
- Обновления: браузер скачивает только маленький `update.json` и установщик по https. `update.json` подписан ключом ECDSA P-256,
  открытый ключ вшит в браузер (`Core/Updater.cs`), а в подписанном файле записаны размер и SHA-256 установщика.
  Подделанный `update.json` или подменённый установщик браузер отклонит и ничего не запустит. Внутри установщика программа
  ещё раз сверяется по SHA-256 перед установкой.

## Настройки

Всё меняется на странице `sneznyj://settings` (меню «≡» → «Настройки» или `Ctrl+,`) и применяется сразу.
Под капотом это `%LOCALAPPDATA%\SneznyjBrowser\settings.json`: тема (`theme`, `accent`), вкладки (`tabsPosition`: `top`/`left`),
левая панель (`leftPanel`: `pinned`/`compact`/`hidden`), стартовая (`startBackground`, `startSnow`, `startClock`), поисковик,
подсказки поисковика, блокировщик, защита от слежки, HTTPS, пароли, спящие вкладки, загрузки, жесты, боковая панель.
Свои домены для блокировки — в `%LOCALAPPDATA%\SneznyjBrowser\blocklist.txt`.
Закладки — `bookmarks.json`, загрузки — `downloads.json`, масштаб сайтов — `zoom.json`, всё в той же папке.

Команды запуска (для ярлыков и скриптов): `SneznyjBrowser.exe sneznyj.com --workspace=analytics --panel=telegram`
(`--panel=off` скрывает панель, `--no-activate` — не выводить окно вперёд и не забирать фокус, `--check-updates` — проверить обновления).

Для проверок без мыши и клавиатуры: `--cmd=…` — `expand-panel`, `collapse-panel`, `menu`, `tabmenu`, `bookmark`, `downloads-popup`,
`newtab`, `reader`, `find`, `findtext:слово`, `open:settings`, `suggest:текст`, `set:ключ=значение`, `dragsim:откуда:куда`,
`spaces-menu`, `panel-url:адрес`, `panel-half`, `click:x:y` (клик в странице через DevTools — считается действием человека,
так проверяются окна входа), `dump` (вкладки и панель → `test-state.json` в папке данных). `--panel=site` — «Любой сайт».

Свои страницы (`https://start.sneznyj/…`) отдаёт сама программа из папки `start` (WebResourceRequested), а не движок
с диска: с виртуальным хостом движок после обновления браузера мог весь сеанс получать ERR_ACCESS_DENIED. Целиком такие
страницы открываются только во вкладке (не во фрейме), их файлы берут только они сами. Если страница всё же не открылась,
браузер повторяет попытку и пишет об этом в `crash.log`. Файлы стартовой пишутся целиком и только если изменились.
`SNEZNYJ_BROWSER_SOFTWARE=1` рисует окно без видеокарты — тогда снимок PrintWindow видно, даже если окно перекрыто.

Вторая, независимая копия браузера со своей папкой данных (для тестов или второго профиля): переменная окружения
`SNEZNYJ_BROWSER_HOME=<папка>` — у такой копии свои вкладки, входы и настройки, и она не мешает основной.

## Сборка

```powershell
.\build.ps1                  # браузер в один файл + установщик → dist\<версия>\SneznyjBrowser-Setup-<версия>.exe
.\build.ps1 -Install         # то же и сразу тихо поставить на этот компьютер (открытый браузер закроется, вкладки сохранятся)
.\tools\make_icon.ps1        # перерисовать значок
```

Нужен только .NET 10 SDK. Что из чего состоит:

- `SneznyjBrowser.csproj` — браузер (WPF + WebView2). Публикуется self-contained single-file win-x64: .NET внутри файла.
- `installer\` — установщик на .NET Framework 4.6.2 (он встроен в Windows 10/11, поэтому установщику ничего не нужно).
  Браузер приклеен к его концу, сжатый LZMS (сжатие из самой Windows, `cabinet.dll`): 127 МБ → 48 МБ.
  Тот же файл без программы ставится как `Uninstall.exe`.
- `tools\ReleaseTool\` — упаковка установщика, подпись и проверка `update.json`. В браузер не входит.

## Как выпустить новую версию

Выпуски делаются вручную на ПК (расписаний и автопубликации здесь нет).

1. Поправить код, проверить: `.\build.ps1 -Install`, запустить браузер.
2. Собрать выпуск:
   ```powershell
   .\release.ps1 -Version 0.2.1 -Notes "Что нового — одна-две строки, их увидят в окошке «Новая версия»"
   ```
   Скрипт ставит номер версии в оба `.csproj`, собирает установщик, подписывает `dist\0.2.1\update.json` ключом,
   проверяет его тем ключом, что вшит в браузер, и кладёт установщик в `Claude Проекты\Программы и боты\Снежный браузер` (старый оттуда убирает).
3. Выложить, чтобы у всех появилось «Обновить» (в течение суток):
   ```powershell
   .\release.ps1 -Version 0.2.1 -Notes "…" -Publish
   ```
   Это `gh release create v0.2.1` в репозитории **Sneznyj/sneznyj-browser** с двумя файлами: установщиком и `update.json`.
   Браузеры смотрят на `https://github.com/Sneznyj/sneznyj-browser/releases/latest/download/update.json`, то есть на последний
   выпуск с отметкой «Latest» (черновики и pre-release не видны). Репозиторий должен быть публичным, но исходники в нём держать
   не обязательно: хватит README и выпусков. Создать один раз: `gh repo create Sneznyj/sneznyj-browser --public`.
4. Закоммитить номер версии: `git commit -am "Снежный браузер 0.2.1"`, `git tag v0.2.1`.

Номер версии — только вида `0.2.1`, и каждый выпуск больше предыдущего: браузер обновляется, только если версия новее.

**Ключ подписи** — `%APPDATA%\Sneznyj\browser-update-key.pem` (создан 19.10.2026, в git его нет и быть не должно).
Сохранить копию в надёжном месте (менеджер паролей, зашифрованная флешка). Если ключ потерять, выпустить обновление
для уже установленных браузеров не получится: придётся всем вручную поставить версию с новым ключом
(`ReleaseTool keygen`, открытый ключ — в `Core/Updater.cs`). Если ключ утёк — так же сменить его и выпустить версию с новым ключом.

**Проверить обновление, ничего не выкладывая** (так проверено 19.10.2026):

```powershell
.\build.ps1 -Version 0.1.90; dist\0.1.90\SneznyjBrowser-Setup-0.1.90.exe --silent     # поставить «старую» версию
.\release.ps1 -Version 0.1.91 -Test -Notes "Тестовая версия"                          # «новая», адрес http://127.0.0.1:8765
python -m http.server 8765 --bind 127.0.0.1 --directory dist\0.1.91                    # сервер обновлений
# тестовая копия со своей папкой данных; в её settings.json — "updateUrl": "http://127.0.0.1:8765/update.json":
$env:SNEZNYJ_BROWSER_HOME = "$env:TEMP\sb-test"; & "$env:LOCALAPPDATA\Programs\SneznyjBrowser\SneznyjBrowser.exe"
```

Через 15 секунд слева внизу появится «Новая версия 0.1.91» → «Обновить» → браузер закроется, установщик поставит новую
версию и откроет браузер с теми же вкладками. Тестовые версии берите ниже настоящей (0.1.9x), а после проверки
верните настоящую: `.\build.ps1 -Install`.
